# 🏢 Sistema de Contratos de Aluguel

Sistema completo para geração e gestão de contratos de aluguel residencial e comercial, com integração ao Supabase (banco de dados em nuvem) e emissão de PDF.

## 📋 Funcionalidades

- ✅ Cadastro de **Locador**, **Locatário** e **Fiador**
- ✅ Busca por CPF com preenchimento automático
- ✅ Cláusulas personalizadas (adicionar/remover)
- ✅ Geração de **prévia do contrato**
- ✅ Emissão de **PDF** com layout profissional
- ✅ Integração com **Supabase** (banco de dados em nuvem)
- ✅ Modo **offline** com localStorage
- ✅ Interface moderna e responsiva

## 🚀 Tecnologias Utilizadas

| Tecnologia | Descrição |
|------------|-----------|
| **HTML5** | Estrutura das páginas |
| **CSS3** | Estilização e responsividade |
| **JavaScript** | Lógica do sistema |
| **Supabase** | Banco de dados e autenticação |
| **pdfmake** | Geração de PDF no frontend |
| **GitHub Pages** | Hospedagem do sistema |
